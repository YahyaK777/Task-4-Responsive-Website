# Task 4 - Responsive Website Using CSS Media Queries

A simple sample website made mobile-friendly using CSS media queries.

## Objective
Convert a desktop-style webpage into a responsive layout that works on desktop, tablet and mobile screens.

## Technologies Used
- HTML5
- CSS3
- Visual Studio Code
- Google Chrome DevTools

## Features
- Responsive navigation on smaller screens.
- Flexible desktop layout.
- Single-column layout on mobile.
- Responsive images.
- Cards change from three columns to two and then one.
- CSS media queries for tablet and mobile screens.
- Viewport meta tag for correct mobile scaling.

## How to Run
1. Open this folder in VS Code.
2. Open `index.html` in a browser.
3. Open Chrome DevTools by pressing `F12`.
4. Click the device toolbar icon or press `Ctrl + Shift + M`.
5. Test different screen sizes, including widths below 768px and 480px.

No installation or build command is required.

## Responsive Breakpoints

| Screen width | Layout |
|---|---|
| Above 768px | Desktop |
| 768px and below | Tablet |
| 480px and below | Mobile |

The website adjusts its navigation, text, cards and images to fit different screen sizes using CSS media queries.
